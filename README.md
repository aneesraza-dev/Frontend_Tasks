# HTML & CSS Practice Tasks

This repository contains 11 HTML & CSS tasks created especially for students and beginners who want to improve their front-end development skills through hands-on practice.

## Purpose of This Repository
The main goal of this repository is to help students:
- Understand basic HTML structure
- Learn CSS styling and layouts
- Practice real-world UI components
- Improve confidence in front-end development

These tasks are practice-based, not theory-focused.

---

## What's Included
- 11 HTML & CSS tasks  
- Beginner-friendly examples  
- Pure HTML & CSS (No frameworks)  
- Clean and easy-to-understand code  

---

## Technologies Used
- HTML5  
- CSS3  

---

## Who Is This For?
- Students learning web development  
- Beginners starting with HTML & CSS  
- Anyone who wants to practice front-end basics  

---

## How to Use
1. Clone or download this repository  
2. Open any task folder  
3. Run the `.html` file in your browser  
4. Practice, modify, and experiment with the code  

---

## Learning Tip
Try to:
- Rebuild the task from scratch  
- Change colors, layouts, and fonts  
- Make the design responsive  

Practice is the key to improvement.
